A. RNN Limitations and Vanishing Gradient Problem
====================================================
-> RNN Accuracy = 62%
-> LSTM Accuracy = 83%
Why the RNN underperformed:
RNN struggled with long support tickets because of the vanishing 
gradient problem. During backpropagation, gradients shrink exponentially 
as they go back through many time steps. This means the RNN effectively 
forgets words that appeared early in the ticket by the time it reaches 
the end of the sequence.


B. How LSTM Solved the Problem
=================================
LSTM uses 3 gates to handle the memory and training across long sequences:
1- Forget Gate: this decides what to discard from the old words
2- Input Gate: this decides what to store from the current new information
3- Output Gate: this decides what part of the memory to output at each step
